# AGENTS.md

## Setup commands
Crear siempre un entorno virtual e instalar allí las dependencias del proyecto
Crear un archivo requirements.txt con las dependencias

##  Codestyle
Utilizar siempre las recomendaciones del PEP8

## Documentation
Crear un archivo README.md donde de incluya:
- Descripción del proyecto
- Tecnologías / frameworks / librería utilizadas
- Comandos o instrucciones de instalación
- Descripción detallada de las funcionalidades implementadas
Crear un archivo ARCHITECTURE.md donde se describan detalladamente las decisiones y tomas de partido realizadas durante la construcción del proyecto.
